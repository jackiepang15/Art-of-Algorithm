# Gaming

## The Legend of Mir

The Legend of Mir 2 is a sprite-based isometric 3-D massively multiplayer online role-playing game developed by Korean-based WeMade Entertainment. There are currently two versions available: Korean and [Chinese](Mir2_Chinese.md).
