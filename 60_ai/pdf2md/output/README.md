# Exercise 10 - Pentagons Composition

## Exercise Description

**第 10 讲 数一数 画一画**

**10 需要多少个正五边形才能组成下面的图形？**

### Problem Statement

This exercise asks to determine the minimum number of regular pentagons required to form a specific geometric shape.

### Exercise Content

The exercise includes:
1. The exercise number (10)
2. The question text ("需要多少个正五边形才能组成下面的图形？")
3. An image showing the target shape to be formed from pentagons

### Source

This exercise is extracted from the first lecture (第 1 讲 数一数 画一画) of the book "奥数教程" (Math Olympiad Tutorial), Grade 1, Chapter 1.
